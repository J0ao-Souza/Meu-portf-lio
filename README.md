# 💻 Meu Portfólio

Bem-vindo ao meu portfólio pessoal!

Este projeto foi desenvolvido com o objetivo de apresentar minha trajetória na área de Desenvolvimento de Sistemas, demonstrar minhas habilidades e reunir alguns dos projetos que venho desenvolvendo durante meus estudos.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## 📌 Sobre o projeto

O portfólio apresenta informações sobre mim, minhas habilidades, tecnologias que estou estudando e projetos desenvolvidos na área de tecnologia.

O desenvolvimento também foi uma oportunidade para praticar conceitos de desenvolvimento web, estruturação de páginas, estilização e responsividade.

## 🎯 Objetivos

- Apresentar meus conhecimentos em desenvolvimento web.
- Compartilhar projetos pessoais e acadêmicos.
- Praticar e aprimorar minhas habilidades de programação.
- Construir minha presença profissional na área de tecnologia.
